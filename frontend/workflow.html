标注工作流

管理员配置从 AI 自动标注到审核、专家复核、最终验收的流转规则。

标准工作流

Stage 1
AI 自动标注
→
Stage 2
审核员校正
→
Stage 3
专家审核员复核
→
Stage 4
管理员验收入库

阶段职责

1. AI 自动标注
输入 image + title + caption，经 S0–S7 八遍流水线（预处理 → Caption 解析 → Grounding → 遗漏发现 → 属性状态动作 → Group/Event → Relation → QC 风险）生成 Candidate；执行 Scene / Entity / Group / Event / Relation 与 QC。
2. 审核员
只能处理分配给自己的任务；负责 BBox、类别、Attribute/State/Action、Scene、Group/Event、Relation 的接受与校正。
3. 专家审核员
复核审核员提交的数据，重点处理专业身份、复杂叙事、不确定术语与跨模态冲突。
4. 管理员
检查流程完成度、阻断 QC、任务归属和版本信息；最终确认 Approved 入库。

流转规则

AI 完成后必须由管理员分配
不允许审核员自行认领未分配样本
专家复核为必经步骤
所有 Reviewed 数据进入指定专家
管理员最终验收
只有管理员可生成 Approved

退回规则

发起角色可退回到典型原因
专家审核员审核员专业身份错误、关系结构不完整、需要补标
管理员专家审核员 / 审核员流程未完成、QC未关闭、数据版本异常
