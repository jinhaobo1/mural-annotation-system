质检规则

规则分 BLOCKING / WARNING / INFO，可配置执行时机和参数。

规则码级别说明执行时机启用操作
QC_SCHEMA_INVALIDBLOCKINGJSON Schema 非法（结构不符合教程 8.2 顶层结构规范）AI落库前 / 提交前是
QC_BBOX_INVALIDBLOCKING实体 bbox 无效（需 [x1,y1,x2,y2] 且 x2>x1、y2>y1）AI落库前 / 导出前是
RELATION_VALIDBLOCKING关系的 subject / object 引用了不存在的节点S6 / 导出前是
MURAL_ID_REQUIREDBLOCKING文档缺少壁画编号 mural_id导出前是
QC_OVERALL_INFOWARNING整体信息检查（教程 8.1.1）：view_type / scene / region 是否遗漏S2 / 审核是
ENTITY_COVERAGEWARNING实体检查（教程 8.1.2）：caption 主要对象是否全部出现；衣服帽子是否被误标成实体；重要器物是否遗漏；bbox 是否对应正确对象S3 / 审核是
SEMANTIC_MIXUPWARNING语义检查（教程 8.1.3）：Attribute / State / Action 是否混淆；有明确客体的动作是否建立 Relation；群体描述是否建立 Group；多角色活动是否建立 Event；数量是否遗漏S5-S6 / 审核是
COUNT_MISMATCHWARNING文本数量与视觉数量不一致（对应教程 8.1.3「数量是否遗漏」）S3 / 审核是
CROSS_MODAL_CONFLICTWARNINGcaption 与视觉预测冲突（跨模态证据需人工裁决）S4 / 审核是
CERTAINTY_CHECKWARNING特殊信息检查（教程 8.1.4）：「似为 / 应为」是否被错误升级为确定标签；probable 事实导出时保留并提示人工复核S7 / 导出前是
EXPERT_TEXT_AS_FACTWARNING特殊信息检查（教程 8.1.4）：专家解释是否被误当成视觉事实审核 / 专家复核是
VISIBILITY_DAMAGEWARNING特殊信息检查（教程 8.1.4）：残损实体是否记录 visibility（clear/partial/occluded/damaged/unclear/missing）S4 / 审核是
INSCRIPTION_MISSWARNING特殊信息检查（教程 8.1.4）：题记是否遗漏；题记应标为 INSCRIPTION 并可建 identifies / labels / names 文字关联S3 / 审核是
