## 一、项目简介
本系统用于**壁画标注结果的导出与展示**，是壁画展示系统的配套工具集。
**核心能力**：
| 能力 | 说明 |
|------|------|
| 📤 数据导出 | 将壁画标注结果导出为 **JSON / CSV / Excel** 三种格式 |
| 🖼️ 可视化展示 | 本地网页展示 15 幅壁画（图片、名称、朝代、简介） |
| 📦 免环境运行 | 已通过 PyInstaller 打包为独立 exe，**无需安装 Python** |
| 📱 便携部署 | 整个文件夹拷贝即用，不写死任何绝对路径 |
**数据字段**（JSON 契约）：
```json
{
  "id": 1,
  "name": "供养人与仙鹤图",
  "dynasty": "宋/西夏",
  "description": "画面绘一立姿男供养人……",
  "site": "敦煌莫高窟",
  "category": "中国壁画",
  "confidence": "中",
  "image": {
    "file_name": "mural_01.jpg",
    "path": "壁画图片\\mural_01.jpg",
    "exists": true
  }
}
```

## 四、常见问题（FAQ）
### Q1：双击 exporter.exe 被杀毒软件拦截 / 报毒怎么办？
**这是 PyInstaller 打包程序的常见误报，不是病毒。** 处理方法任选其一：
| 方法 | 操作步骤 |
|------|----------|
| ① 弹窗允许 | 杀毒软件弹窗中选择「**允许运行**」/「**信任此文件**」 |
| ② 安全中心放行 | Windows 安全中心 → 病毒和威胁防护 → **保护历史记录** → 找到被拦截项 → 操作选「**允许**」 |
| ③ 添加白名单 | 将 `Task B` 文件夹添加到杀毒软件的**排除项/白名单** |
| ④ 360/火绒 | 弹窗中勾选「**信任此程序**」，或在「信任区」添加该文件夹 |
> 💡 若企业电脑有统一安全策略，请联系 IT 管理员将 `exporter.exe` 加入白名单。
### Q2：如何通过外部工具（记事本）读取校验 JSON 文件？
**方法一：记事本（最通用）**
1. 右键 `壁画标注结果.json` → **打开方式** → **记事本**
2. 检查内容是否为正常中文（无乱码方块 `□` 或问号 `?`）
3. 确认字段是否齐全：`id`、`name`、`dynasty`、`description`
**方法二：VS Code（推荐，带格式）**
1. 用 VS Code 打开 json 文件
2. 按 `Shift + Alt + F` 自动格式化，结构一目了然
**方法三：浏览器**
1. 直接把 json 文件拖进 Chrome/Edge 窗口即可查看
**校验要点清单**：
- ✅ 编码为 **UTF-8**（无 BOM 也可正常显示）
- ✅ 中文正常，如 `"name": "供养人与仙鹤图"`
- ✅ 记录数为 **15 条**
- ✅ 每条含 `id`（数字）、`name` / `dynasty` / `description`（文本）
- ✅ `description` 为完整简介（通常 80~150 字）
### Q3：双击 exe 后窗口一闪而过？
在文件夹地址栏输入 `cmd` 回车打开命令行，再输入 `exporter.exe` 运行，
即可看到完整报错信息。最常见原因是数据库文件被移动或改名。
### Q4：CSV 用 Excel 打开乱码？
本系统导出的 CSV 已带 **UTF-8 BOM**，正常双击打开不会乱码。
若仍异常，请用 Excel「数据 → 从文本/CSV 导入」并选择 **UTF-8** 编码。
### Q5：提示「未找到数据库文件」？
exe 已内嵌数据库，正常情况下不会出现此提示。若出现，请确认：
1. `exporter.exe` 文件完整（约 9.3MB，未被杀毒软件截断）
2. 或把 `壁画数据库.db` 放在 exe 同一文件夹作为备用
### Q6：想更新标注数据？
用新的 `壁画数据库.db` 替换旧文件（文件名保持不变），重新运行
`exporter.exe` 即可导出最新数据。

## 五、跨平台说明（Mac / Linux）
Windows 用户请忽略本节。Mac / Linux 用户请使用 `.sh` 脚本：
### 启动方式
```bash
# 进入解压后的目录
cd "Task B"
# 方式一：直接执行
bash 启动壁画系统.sh
# 方式二：先赋权再执行（推荐）
chmod +x 启动壁画系统.sh
./启动壁画系统.sh
```
### 脚本会自动完成
| 步骤 | 自动操作 |
|------|----------|
| [1/4] | 检测 Python（依次查找 `python3`、`python`），未找到给出安装指引 |
| [2/4] | 检查虚拟环境 `venv`，不存在则自动创建 |
| [3/4] | 读取 `requirements.txt` 自动安装依赖（已装则跳过） |
| [4/4] | 自动运行 `server.py`（展示系统）或 `exporter.py`（导出工具） |
### 前置条件（Mac/Linux）
| 系统 | 安装 Python 命令 |
|------|------------------|
| macOS | `brew install python3` |
| Ubuntu / Debian | `sudo apt install python3 python3-venv` |
| CentOS / RHEL | `sudo yum install python3` |
> ⚠️ **注意**：`exporter.exe` 是 Windows 专用程序，Mac/Linux 上无法运行。
> Mac/Linux 用户请使用 `.sh` 脚本 + `exporter.py` 源码方式导出数据。
### Mac/Linux 导出数据
```bash
cd "Task B"
bash 启动壁画系统.sh          # 脚本会自动装依赖并运行
# 或手动方式：
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python exporter.py all
```
