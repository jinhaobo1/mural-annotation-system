# gold_standard · 金标准标注数据（A乙）

15–20 张壁画图的人工精标数据，作为评测基准。

## 5 层结构（场景 → 区域 → 事件 → 组 → 实体）

每个 `MURAL-*.json` 对应一张图，字段：

| 字段 | 层 | 说明 |
|------|-----|------|
| `mural_id` | — | 壁画编号 |
| `caption` | — | 原始 caption |
| `scene` | 场景 | 一级场景 |
| `regions` | 区域 | 画面分区 |
| `events` | 事件 | 事件及表演者/观察者 |
| `groups` | 组 | 群组/子组 |
| `entities` | 实体 | 实体 + 类别层级 + 事实 |

## 关键约束

- 标注时**不看 A甲 的实现代码**，避免评测集迁就引擎
- 选图与 B丙 的演示种子图同套（一套图两用）
