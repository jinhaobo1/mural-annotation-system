# taxonomy · 分类体系契约文件（A乙）

本目录是 **A甲（标注引擎 S2）的输入**，也是全组**第一优先级**的交付物。

## taxonomy.json 结构

| 字段 | 说明 | 预期数量 |
|------|------|---------|
| `entity_classes` | 一级实体类别 | 11（人物/动物/神怪/器物/家具/车马/建筑/植物天象/天象/装饰纹样/文字题记） |
| `human_subclasses` | HUMAN 的二级类别 | 9（主人类/侍从类/官吏类/武职类/乐舞表演类/劳作类/宗教人物类/历史人物类/普通人物类） |
| `scenes` | 一级场景 | 14 |
| `relation_families` | 关系族（含关系类型） | 5 族共 43 条（空间 15 / 隶属 4 / 互动 9 / 叙事 12 / 文字 3） |

## 契约规则

- 对照教程第 2 章整理，逐项核对通过后才能交付 A甲
- 冻结后任何修改须经管理员确认并当日同步两组（咬合点 2）
- 做完先交已完成部分，不得整块压住（咬合点 1）
